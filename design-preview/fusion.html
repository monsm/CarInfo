融合 · 十种 · 都能手滑

地图是载体，底部那条手滑模式条切的是功能

骨架十套完全一样，一个字都不改：系统地图当取景框永远在 + 底部一条能手滑的模式条 （iOS 27 相机那个特效：手指拖着走、中间的放大变亮、两侧缩下去、松手吸附到最近一格）+ 一个位置永不变的主按钮 —— 那是相机的快门：按钮永远在同一个地方， 按下去干什么，由当前模式决定。

一个模式 = 一整套不同的功能界面，不是换几个数字：找车是一套、锁车是一套、空调是一套、 充电是一套、记录是一套。手滑过去的时候，整套界面连同地图上的图层一起交叉过渡 —— 这就是「切换不同的功能」。

十套的差别在功能界面与地图的融合方式（不是颜色，也不是换切换器）： 底部面板 / 底部大卡 / 悬浮卡 / 右侧栏 / 中央圆环 / 分屏 / 顶部抽屉 / 地图内标注 / 角落地图 / 水印。

固定件（十套一致）① 系统地图 ＝ 取景框　② 底部手滑模式条（可拖 · 缩放 · 吸附）　③ 位置不变的主按钮（功能随模式变）
变的部分功能界面与地图怎么摆：面板 / 大卡 / 悬浮 / 侧栏 / 圆环 / 分屏 / 顶抽屉 / 地图内标注 / 角落地图 / 水印
怎么试按住手机底部那条模式条左右拖 —— 中间的会放大变亮、地图图层交叉淡入、松手吸附；也可以直接点某个模式名
