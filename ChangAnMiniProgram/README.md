# ChangAnMiniProgram · 长安车管家（微信小程序 · v7 夜航版）

长安车联网车控小程序。v3 完成 Tesla 式极简重构；v4 把高价值原始字段全部设计进界面；v5 加统一分析层；v6 引入 Apple Liquid Glass × Tesla；**v7「NIGHT DRIVE 夜航」把构图系统整个重做**——从“黑底玻璃表”升级为“场景化液态玻璃”：

- **概念**：近黑画布上只有一处冷色月光；每个主屏有一件“发光的物体”（车侧剪影 / SOC 光环 / 俯视车形），玻璃因为折射物体而有了层次；页面用「大物件 + 留白 + 细字」三个层级交错，不再等宽堆卡；
- **场景美术系统 `utils/scene.js`**：纯内联 SVG 手绘——`carSideURI`（侧视 EV，充电时光带增亮 + 车底辉光）、`carTopURI`（俯视车形，胎压卡底图）、`haloURI`（SOC / 健康评分的细圆环）；`barsURI` 升级为渐变柱 + 中位参考虚线 + 越界柱自动标红；
- **设计令牌 `app.wxss`**：冷灰字阶（白 / 灰 / 暗灰 / 更暗灰）、玻璃配方（顶高光 + 底厚度 + 细描边，hero 加 45° 扫光）、圆角分级（hero 44 / 模块 28 / 内件 20）、段间距分层 24/32/48rpx、模糊纪律（每屏 blur ≤ 4，其余纯半透明填充）；正常态消色，语义色只在异常与进行中出现；**v7.2 间距纪律**：全局模块间距恢复 32rpx 统一呼吸节奏、玻璃卡内边距统一 36rpx、发丝线降噪为 0.045~0.06、光环与容器等高防裁切、运行快览改为非对称构图、统计改编辑部式列（去胶囊按钮感）、弹层限高 `100vh-40rpx` 防底部按钮被遮挡、消息展开显示完整正文（不再只给地点/车牌/ID 这类调试字段）；
- **首页构图**：场景 hero 卡（车 + SOC 光环 + 大数字 + 续航 + 运行四栏）→ 今日关注（全绿一行 / 异常只亮出问题域）→ 电池一致性图 + 角标 → 车身状态条 + 胎压俯视（四轮叠值）→ 座舱 / 位置左右分栏；每个深潜页（电池 / 健康 / 档案）有自己的光环 hero 或名片卡；
- 数据链路与功能语义不变（登录 / 云函数 / 指令轮询 / 缓存 / v5 分析层），字段语义与桌面版逐一对齐；页面 JS 逻辑未动（仅 hero 展示字段与场景图渲染）。

## 运行

1. 微信开发者工具「导入项目」选择本目录；
2. 「云开发」开通，将环境 ID 填入 `utils/config.js` 的 `CLOUD_ENV`；
3. 右键 `cloudfunctions/changanProxy` →「上传并部署：云端安装依赖」；
4. 登录后自动进入车况首页。详见 v2 遗留排查说明：短信失败先重部署云函数，必要时 `LOGIN_VIA_DIRECT = true` 直连登录（工具勾选“不校验合法域名”）。
